# Agent Index

Read this file after consulting the codebase knowledge graph.

## By Task

- General code or test work: read `lessons.md` and `todo.md`.
- Public API or documentation changes: also read `documentation.md`.
- New package or scaffold work: also read `package-replication-guide.md` and `new-project.md`.
- Release, deploy, version bump, or publish work: also read `deploy-and-release-guide.md` and `documentation.md`.

Keep these files versioned. They are excluded from the npm tarball through `.npmignore`, not through Git.
