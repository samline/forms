Each preview below is a real form driven by the published API, the same component used on Home and on the Examples page. Open **Explore the code** under a preview to copy its HTML, CSS and JavaScript, separately or as one complete file, in HTML / CDN and Package / ESM versions. **Try it** buttons start from a fresh form, write values with `setValue()` and press submit when the scenario needs it. **Reset** restores the authored form.
